# DevOps Lab

A production-style DevOps platform project used to demonstrate the full application delivery lifecycle:

Code → Git → CI/CD → Container → Infrastructure → Kubernetes → Monitoring

## Goal

Build and operate a small containerized microservice through a complete DevOps workflow, including:

- source control
- automated testing and CI/CD
- containerization
- infrastructure as code
- Kubernetes deployment
- monitoring and observability
- troubleshooting and recovery
